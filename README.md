# arcadia
An arcade game containing various mini-games featuring an arcade-like experience

## Controls
move with arrow keys or WASD.  
interact with E.  
Jump with space bar in minigames.  
In arcade minigames move with arrow keys only.  
Press Esc in any minigame to exit to the arcade.  

## Built with
[Godot Game Engine v4.7.2.stable](https://godotengine.org)
